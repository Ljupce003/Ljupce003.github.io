An intelligent stock analysis and forecasting platform for the Macedonian Stock Exchange. The system features a hybrid architecture that integrates a Spring Boot orchestrator with Python-based AI modules for automated web scraping (Playwright), technical indicator analysis, NLP sentiment processing, and LSTM-driven price predictions.

A custom-built monitoring dashboard provides real-time visibility into asynchronous script execution and system health.
