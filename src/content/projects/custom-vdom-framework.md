A lightweight, component-based frontend web framework built entirely from scratch in vanilla JavaScript. Designed to explore the underlying mechanics of modern UI libraries, the framework implements a custom Virtual DOM (VDOM) and a custom reconciliation algorithm for efficient DOM updates.

It features a complete component architecture supporting state management, stateful components, lifecycle hooks (mounting/unmounting), and event binding. The project encompasses the full library development lifecycle, culminating in the framework being bundled and published to the NPM registry.
