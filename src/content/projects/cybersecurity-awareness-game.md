An interactive browser-based educational game that teaches players to recognize safe and risky digital behaviors through fast-paced decision making. The game is implemented using the HTML5 Canvas API with all visuals, UI elements, and animations rendered manually through JavaScript.

Gameplay is divided into multiple stages using separate canvas contexts: the first two stages focus on password-strength recognition and security choices using dynamically generated text-based challenges, while the third stage introduces image-based cybersecurity scenarios such as phishing detection, social media privacy choices, and software update decisions.

The application uses a custom JavaScript game loop for rendering and timing, state management for switching between gameplay phases, and randomized question and image selection to keep each session different. The system also supports multilingual content through a translation layer that dynamically loads interface text and questions. Designed as a lightweight educational game that combines real-time interaction, randomized challenges, and subtle visual cues to train players to evaluate online security situations critically. The game was made by me and my team.
